# 我的家常菜更新源

这个公开仓库只存放《我的家常菜》Android 应用使用的菜谱更新包，不包含收藏、做过记录、购物清单、应用签名或其他私人数据。

- `recipes.json`：完整菜谱数据包。
- `recipeVersion`：每次发布新菜谱时必须递增。
- `notes`：应用在更新确认框中显示的简短说明。

应用只有在用户主动点击“检查菜谱更新”时才读取这个文件。下载后会先检查数据格式和必要字段，再由用户确认是否保存到手机本地。

其中 25 道新增菜参考了 [Anduin2017/HowToCook](https://github.com/Anduin2017/HowToCook)（检索时 102,328 Stars，The Unlicense），并重新整理为单人份精确用量、无猪肉、无酒类调味和适合德国采购的版本。
